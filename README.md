# LanChat — پیام‌رسان شبکه محلی ویندوز

نمونه‌ی اولیه‌ی یک پیام‌رسان LAN با رابط فارسی، بدون سرور مرکزی و قابل ساخت به فایل اجرایی مستقل ویندوز.

## امکانات نمونه اولیه
- شناسایی خودکار همتاها با UDP broadcast در شبکه محلی
- گفت‌وگوی متنی مستقیم با TCP
- ارسال فایل به پوشه‌ی `Downloads/LanChat` در رایانه مقصد
- ارسال متن کلیپ‌بورد
- نام نمایشی و انتخاب عکس پروفایل (نمایش کامل عکس در نسخه بعدی تکمیل می‌شود)
- آیکون اختصاصی LanChat
- ساخت خودکار `LanChat.exe` با GitHub Actions

## ساخت EXE در GitHub
1. این پروژه را در مخزن GitHub آپلود کن.
2. به بخش **Actions** برو.
3. گردش‌کار **Build LanChat for Windows** را اجرا کن.
4. بعد از موفقیت، در صفحه‌ی اجرای workflow بخش **Artifacts** فایل `LanChat-Windows` را دانلود و از ZIP خارج کن.

## ساخت محلی
```powershell
py -m pip install -r requirements.txt
py main.py
```

## نکات مهم
- هر دو دستگاه باید در شبکه‌ی محلی قابل دسترس باشند؛ شبکه‌ی Guest، جداسازی کلاینت‌ها، VPN یا فایروال ممکن است کشف را مسدود کنند.
- پورت‌های UDP `39871` و TCP `39872` استفاده می‌شوند.
- این نسخه نمونه اولیه است؛ رمزنگاری، احراز هویت، تأیید دریافت فایل، اجرای خودکار با شروع ویندوز، تاریخچه پایدار و نمایش عکس پروفایل هنوز کامل نشده‌اند.
- ظرفیت نامحدود تضمین‌شدنی نیست؛ محدودیت به شبکه و سخت‌افزار بستگی دارد.
- فقط در شبکه‌ی مورد اعتماد آزمایش شود؛ این نسخه برای تبادل اطلاعات حساس مناسب نیست.
