# LanChat 1.1.0 — پیام‌رسان شبکه محلی ویندوز

این نسخه با تمرکز ویژه بر **کشف خودکار مدیر شبکه و نمایش فهرست کاربران آنلاین** به‌روزرسانی شده است.

## تغییرات مهم نسخه 1.1.0
- کشف مدیر با UDP روی همه آدرس‌های broadcast قابل‌شناسایی کارت‌های شبکه IPv4، علاوه بر `255.255.255.255`؛ این کار در شبکه‌هایی که broadcast عمومی را عبور نمی‌دهند کمک می‌کند.
- پاسخ کشف نسخه‌دار (`LANCHAT_DISCOVER_V2`) برای جلوگیری از اشتباه گرفتن پاسخ‌های قدیمی.
- سرور فقط دستگاه‌هایی را آنلاین اعلام می‌کند که در ۱۲ ثانیه اخیر heartbeat فرستاده‌اند.
- فهرست کاربران عادی فقط کاربران آنلاین را نشان می‌دهد؛ کنار نام، وضعیت سبز و IP نمایش داده می‌شود و تعداد آنلاین‌ها در عنوان گفت‌وگو می‌آید.
- فهرست آنلاین مدیر نیز بر اساس آخرین heartbeat محاسبه می‌شود.

## نحوه کار
یک رایانه باید در تنظیمات به‌عنوان **مدیر شبکه** فعال باشد و LanChat آن رایانه باز بماند. سایر رایانه‌ها در همان شبکه محلی، مدیر را خودکار پیدا می‌کنند و پس از اتصال، با heartbeat دوره‌ای در فهرست آنلاین ظاهر می‌شوند. در این نسخه، مدل ارتباطی مرکزی است؛ بنابراین برای نمایش یک فهرست مشترک، مدیر شبکه باید روشن و در دسترس باشد.

## ساخت فایل EXE مستقل در GitHub
1. محتوای پوشه `LanChat` را در مخزن GitHub قرار بده.
2. در GitHub به بخش **Actions** برو و workflow با نام **Build LanChat for Windows** را اجرا کن (یا تغییرات را push کن).
3. از بخش Artifacts فایل `LanChat-Windows-1.1.0` را دانلود و ZIP آن را استخراج کن.

## ساخت محلی در Windows
```powershell
py -m pip install -r requirements.txt
py main.py
```

## پورت‌ها و عیب‌یابی
- UDP `39873`: کشف خودکار مدیر شبکه.
- TCP `39872`: اتصال، heartbeat و پیام‌ها.
- اجازه دسترسی LanChat را در Windows Firewall بده؛ در صورت نیاز این دو پورت را برای شبکه Private مجاز کن.
- تمام رایانه‌ها باید روی یک شبکه محلی قابل‌دسترسی باشند. شبکه Guest، گزینه AP/client isolation، VPN، چند VLAN یا فایروال ممکن است کشف را مسدود کند.
- برای آزمون، ابتدا مدیر را اجرا کن، سپس LanChat را روی رایانه دوم اجرا کن و تا چند ثانیه برای ظاهر شدن نام آن در فهرست آنلاین صبر کن.

## محدودیت‌ها
این بسته از نظر نحوی بررسی شده، اما در این محیط امکان آزمون واقعی بین چند رایانه ویندوزی و شبکه فیزیکی وجود ندارد؛ بنابراین کشف در شبکه واقعی باید آزمایش شود. کشف UDP به‌تنهایی رمزنگاری یا احراز هویت قابل اتکا ایجاد نمی‌کند. فقط در شبکه مورد اعتماد استفاده کن و اطلاعات حساس نفرست. انتقال فایل در این نسخه هنوز فعال نیست.
