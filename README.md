# LanChat — پیام‌رسان شبکه محلی ویندوز

نسخه توسعه‌یافته و قابل ساخت به فایل مستقل `LanChat.exe`. همه دستگاه‌ها از یک فایل اجرایی استفاده می‌کنند؛ نقش مدیر یا کاربر عادی هنگام راه‌اندازی تعیین می‌شود.

## امکانات پیاده‌سازی‌شده در این نسخه
- رابط فارسی و آیکون اختصاصی
- اجرای کمینه و انتقال با ضربدر به System Tray؛ خروج کامل از منوی آیکون
- اجرای خودکار با شروع ویندوز از طریق کلید Run کاربر جاری
- ذخیره تنظیمات کاربر در `%APPDATA%/LanChat/profile.json`
- ذخیره تاریخچه پیام‌های ارسال و دریافت در فایل متنی `%APPDATA%/LanChat/messages.txt`
- حالت مدیر مرکزی با سرویس TCP و حالت کلاینت
- تولید کد جفت‌سازی ۸ کاراکتری و مصرف یک‌باره کد هنگام جفت‌سازی
- فهرست کاربران جفت‌سازی‌شده و وضعیت اتصال تقریبی
- پیام خصوصی، ارسال همگانی و پیام به گروه
- اعلان پیام‌ها از طریق اعلان‌های سیستم‌عامل
- پنل مدیر برای مسدودکردن/رفع مسدودی و بستن/بازکردن ارسال پیام کاربر
- تنظیم مرکزی اجازه ارسال پیام کاربران عادی
- ساخت گروه با قالب `نام گروه = شناسه‌کاربر۱,شناسه‌کاربر۲`
- گردش‌کار GitHub Actions برای ساخت EXE ویندوز

## راه‌اندازی شبکه
1. روی یک رایانه، LanChat را اجرا کن و به تنظیمات > شبکه و نقش برو.
2. «راه‌اندازی این رایانه به‌عنوان مدیر» را انتخاب و برنامه را دوباره اجرا کن.
3. دوباره به تنظیمات مدیر برو و «تولید کد جفت‌سازی جدید» را بزن. کد را فقط به کاربر مورد اعتماد بده؛ کد پس از یک جفت‌سازی مصرف می‌شود.
4. روی هر کلاینت، در تنظیمات IP رایانه مدیر و کد را وارد و جفت‌سازی کن.
5. اجازه دسترسی LanChat به شبکه خصوصی را در Windows Firewall بده. رایانه مدیر باید هنگام تبادل پیام آنلاین باشد.

## شبکه و امنیت
- پورت TCP `39872` روی رایانه مدیر استفاده می‌شود. در فایروال فقط شبکه خصوصی مورد اعتماد را مجاز کن.
- این نسخه نمونه کاربردی اولیه است، نه محصول امنیتی نهایی. ترافیک شبکه در این نسخه رمزنگاری سرتاسری ندارد؛ روی شبکه عمومی یا برای اطلاعات حساس استفاده نکن.
- کد جفت‌سازی یک‌بارمصرف است، اما اتصال‌ها هنوز TLS/رمزنگاری سرتاسری ندارند. برای محیط سازمانی باید TLS، مدیریت امن کلیدها، تأیید فایل دریافتی و آزمون امنیتی اضافه شود.
- مدیر هنگام آفلاین بودن در دسترس نیست. صف پیام‌ها روی رایانه مدیر نگهداری می‌شود.
- انتقال فایل عمداً در این نسخه از مسیر سرور مرکزی فعال نشده است؛ این قابلیت باید با کنترل دسترسی و تأیید گیرنده پیاده‌سازی شود.
- مدیریت گروه‌ها از پنل مدیر با قالب خطی انجام می‌شود. شناسه کاربران در جدول مدیریت کاربران نمایش داده می‌شود.
- در ویندوز، Windows Defender ممکن است برای EXE تازه‌ساخته‌شده هشدار ناشناخته بودن بدهد؛ این به‌تنهایی اثبات بدافزار بودن نیست، ولی فقط کد و فایل ساخته‌شده از مخزن خودت را اجرا کن.

## اجرای توسعه‌دهنده
```powershell
py -m pip install -r requirements.txt
py main.py
```
