# LanChat 1.6.0

پیام‌رسان مستقیم و مستقل برای شبکه محلی (LAN) ویندوز؛ بدون نقش مدیر، بدون سرور مرکزی و بدون حساب کاربری مرکزی.

## قابلیت‌ها
- هر رایانه یک همتای مستقل است؛ هیچ رایانه‌ای نقش مدیر یا سرور مرکزی ندارد.
- کشف خودکار همتاها از طریق UDP broadcast روی شبکه IPv4 و نمایش فهرست آنلاین.
- ارسال مستقیم پیام از یک رایانه به رایانه دیگر روی TCP.
- ذخیره محلی پیام‌های ارسال‌شده و دریافت‌شده در `%APPDATA%\LanChat\messages.txt`، در صورت فعال بودن گزینه ذخیره پیام.
- تنظیم نام نمایشی، پوسته روشن/تیره، نوع و اندازه فونت، اعلان پیام و پنجره روی همه برنامه‌ها.
- با زدن × پنجره مخفی می‌شود و برنامه کنار ساعت ویندوز در System Tray فعال می‌ماند؛ برای خروج کامل از منوی آیکون سینی، «خروج کامل» را انتخاب کنید.
- اعلان شامل پیام بالای پنجره‌ها نمایش داده می‌شود و در صورت فعال بودن اعلان، اعلان سینی ویندوز و صدای پیام نیز تلاش می‌شود.
- ایمیل تماس: `hamedmohammadinikche@gmail.com`

## نکات مهم شبکه
- برنامه باید روی هر دو رایانه اجرا باشد تا پیام مستقیم دریافت شود. **هیچ سرور یا رایانه‌ای برای رله پیام‌ها وجود ندارد**؛ اگر رایانه گیرنده خاموش باشد یا LanChat بسته باشد، پیام تحویل نمی‌شود و در صف ابری ذخیره نمی‌شود.
- رایانه‌ها باید در یک شبکه محلی قابل‌دسترسی باشند. شبکه‌های مهمان، جداسازی کلاینت در مودم، VPNها و بعضی شبکه‌های شرکتی ممکن است Broadcast یا ارتباط مستقیم را مسدود کنند.
- در فایروال ویندوز برای LanChat یا Python اجازه ارتباط در شبکه Private بدهید. پورت TCP `39872` و UDP `39873` استفاده می‌شوند.
- شناسه ثابت هر نصب در `%APPDATA%\LanChat\profile.json` ذخیره می‌شود. حذف این فایل شناسه جدیدی ایجاد می‌کند.
- پیام‌ها رمزنگاری سرتاسری نشده‌اند؛ برای شبکه‌های حساس استفاده نکنید.
- فهرست آنلاین بر اساس پیام‌های کشف دوره‌ای است و ممکن است چند ثانیه برای به‌روزرسانی زمان ببرد.

## ساخت EXE مستقل در GitHub
1. فایل‌های این پوشه را در مخزن GitHub قرار دهید.
2. در Actions گردش‌کار `Build LanChat for Windows` را اجرا کنید.
3. Artifact با نام `LanChat-Windows-1.5.0` را دریافت کنید؛ فایل داخل آن `LanChat.exe` است.

این نسخه در محیط توسعه از نظر نحوی بررسی می‌شود. برای اطمینان از کشف خودکار باید آن را روی دو رایانه واقعی در شبکه موردنظر آزمایش کنید.


## امکانات نسخه 1.3.0
- ارسال پیام در پس‌زمینه برای جلوگیری از قفل شدن پنجره هنگام اتصال.
- ارسال همگانی به کاربران آنلاین و ارسال به گروه‌های محلی.
- ساخت گروه و تخصیص کاربران به گروه از سمت هر نصب. توجه: گروه‌ها محلی‌اند و خودکار بین رایانه‌ها همگام نمی‌شوند.
- انتخاب فونت و اندازه فونت، صدای اعلان و قرار گرفتن پنجره روی همه پنجره‌ها.
- ارسال همگانی و گروهی مستقیم به کاربران آنلاین؛ گیرنده باید برنامه را باز داشته باشد.

نکته: اعلان‌های ویندوز به تنظیمات اعلان سیستم و موجود بودن System Tray وابسته‌اند. شبکه و فایروال ممکن است ارسال مستقیم را مسدود کنند.


## امکانات نسخه 1.4.0
- اندازه فونت از 8 تا 28 در تنظیمات قابل تغییر است و روی رابط برنامه اعمال می‌شود.
- بستن پنجره با × برنامه را به سینی سیستم می‌فرستد؛ برای جلوگیری از بسته شدن ناخواسته، خروج از منوی سینی انجام می‌شود.
- اعلان جایگزین داخل برنامه در بالای صفحه برای پیام‌های دریافتی وقتی پنجره فعال نیست، به همراه تلاش برای اعلان سینی و صدای پیام.
- آیکون برنامه بازطراحی شده است.

## سازگاری ویندوز
گردش‌کار فعلی با PySide6 و Python 64 بیتی، EXE برای ویندوز 64 بیتی جدید می‌سازد. این پروژه در وضعیت فعلی تضمین‌شده برای Windows 32-bit یا Windows 7 نیست؛ پشتیبانی واقعی از این سیستم‌ها نیازمند نسخهٔ جداگانه و فناوری رابط کاربری سازگار است.


## امکانات نسخه 1.5.0
- گزینهٔ اجرای خودکار پس از ورود کاربر به ویندوز از طریق کلید Run در رجیستری کاربر جاری.
- تعیین مدت نمایش اعلان از 2 تا 60 ثانیه.
- نمایش شماره نسخه هر کاربر در فهرست آنلاین.
- پس از دریافت Beacon از نسخه جدیدتر، کلاینت به‌صورت خودکار فایل EXE را از همان همتای جدیدتر دریافت و در `%APPDATA%\LanChat\updates` ذخیره می‌کند؛ سپس مسیر فایل در نوار وضعیت نمایش داده می‌شود. برای جایگزینی، کاربر باید برنامهٔ فعلی را ببندد و فایل دانلودشده را اجرا کند. نصب/اجرای خودکار انجام نمی‌شود.
- در ارسال گروهی، گزینه توقف 60 یا 120 ثانیه‌ای ارسال برای کاربران آنلاین نسخه 1.5.0 اضافه شده است؛ یک دکمه مستقل نیز برای ارسال درخواست توقف به تمام کاربران آنلاین وجود دارد.

### محدودیت‌های مهم نسخه 1.5.0
- به‌روزرسانی همتا‌به‌همتا فقط وقتی کار می‌کند که رایانهٔ ارائه‌دهنده نسخهٔ جدیدتر، LanChat را اجرا داشته باشد و از نسخهٔ EXE ساخته‌شده استفاده کند. اجرای سورس پایتون فایل EXE برای توزیع ندارد.
- فایل دریافتی با SHA-256 از نظر خرابی انتقال بررسی می‌شود؛ این هش امضای دیجیتال ناشر نیست. بنابراین فایل را فقط از رایانه‌ای در شبکه دریافت کنید که به آن اعتماد دارید. برنامه فایل را خودکار اجرا یا نصب نمی‌کند.
- توقف ارسال یک پیام کنترلی در شبکه محلی است، نه قفل امنیتی غیرقابل دور زدن. فقط کاربران آنلاین با نسخه سازگار آن را اعمال می‌کنند؛ کاربران آفلاین یا نسخه‌های قدیمی ممکن است از آن پیروی نکنند.
- برای اجرای خودکار، برنامه در رجیستری حساب ویندوز فعلی ثبت می‌شود؛ این گزینه برای همه کاربران ویندوز جداگانه تنظیم می‌شود.


## امکانات نسخه 1.6.0
- پوستهٔ جدید «Command Prompt» با پس‌زمینهٔ مشکی واقعی، متن خاکستری روشن، کنترل‌های تخت و انتخاب آبی، با الهام از محیط Windows Command Prompt.
- فونت پیش‌فرض Tahoma برای نمایش مناسب حروف فارسی؛ کاربر همچنان می‌تواند فونت و اندازه را از تنظیمات تغییر دهد.
- پوسته‌های تیره و روشن قبلی نیز در فهرست تنظیمات باقی مانده‌اند.

نکته: ظاهر برنامه از Command Prompt الهام گرفته است و خود برنامه همچنان رابط گرافیکی مستقل دارد؛ این پوسته به معنی اجرای برنامه داخل cmd.exe نیست.
